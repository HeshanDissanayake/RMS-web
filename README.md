# RMS-web

The web frontend of RMS: shows a research project's state and progress live, from [RMS-manager](../RMS-manager/)'s API. Threads, milestones, experiments and results, builds and where they came from, locks, disk, and the commands running per thread with a live console preview.

**Status:** initialised 2026-11-11; nothing built yet. Owner's private work (side project of `~/working_dir/LLVM-regsw`). It depends on RMS-manager's API, which does not exist yet (RMS-manager stage 3).

**Read first:** [`NOTES.md`](NOTES.md). Design of the data and rules: [`../RMS-manager/NOTES.md`](../RMS-manager/NOTES.md).
